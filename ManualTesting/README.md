# Manual Testing Templates

Reusable QA documents for manual testing. The examples use a generic
e-commerce login, cart and checkout flow. All data is sample data written for
practice, with no client or employer information.

## Excel templates
| File | Purpose |
|---|---|
| `test-scenario-template.xlsx` | High-level scenarios to cover per module |
| `test-case-template.xlsx` | Detailed test cases: steps, test data, expected and actual results |
| `traceability-matrix-template.xlsx` | Maps requirements to test cases and shows coverage |
| `test-report-template.xlsx` | Test execution results per case, with linked bug IDs |
| `bug-tracker-template.xlsx` | Defect log with severity, priority and status |
| `bug-summary-template.xlsx` | Pass/fail counts and open bugs |

## Document templates
| File | Purpose |
|---|---|
| `test-plan-template.md` | Scope, approach, environment, schedule, risks |
| `bug-report-template.md` | Detailed single bug report with an example |
| `test-summary-report-template.md` | End-of-cycle results and sign-off |

## How the documents connect
Requirement, then Test Scenario, then Test Case, then Execution Result, then Bug,
then Summary Report. IDs link them: REQ-01, TS_001, TC_001, BUG-001.

## How to use
1. Download the template you need.
2. Replace the sample rows with your own data.
3. Keep the Document History sheet up to date.
